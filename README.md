# 어디가유 (eodigayu) — 발표용 웹 프로토타입

키오스크와 안드로이드 휴대폰에서 각각 사용하는 **분리된 웹 화면**입니다. 명칭과 캐릭터는 임시 디자인입니다.

## 이번에 합의한 범위

- 캐릭터형 상담사, 한국어·영어, 준비된 상담 대화(실제 AI/음성 인식 연결 없음)
- 대전대학교 → 대전역 안내. 장소 이름만 실제이며 노선·정류장 순서·시간은 모두 발표용 가상 데이터
- 추천 경로 안내 → 휴대폰 이어받기 동의 → 개인별 링크/QR → 휴대폰 경로 받기 → 탑승 → 이동 → 하차 안내
- 별도 발표자 화면에서 이동 상태 변경. 휴대폰은 서버의 변경 내용을 주기적으로 조회
- 같은 Wi-Fi나 핫스팟을 요구하지 않으려면 **인터넷에서 접근 가능한 HTTPS 서버에 배포 필요**

## 로컬 실행

현재 PC에서는 `start.cmd`를 더블클릭하면 서버를 실행할 수 있습니다. 켜진 창은 시연하는 동안 유지하세요. 이미 서버가 실행 중이면 중복 실행하지 말고 아래 주소로 접속합니다.

다른 PC는 Node.js가 설치된 상태에서 이 폴더를 터미널로 열고:

```powershell
npm install --ignore-scripts
npm start
```

`http://localhost:3080`을 브라우저로 엽니다. 로컬 서버만 실행하면 다른 네트워크의 휴대폰에서는 연결할 수 없습니다. 키오스크·모바일·발표자 화면은 PC의 별도 탭으로 먼저 검토할 수 있습니다.

HTML 파일을 직접 더블클릭하면 상담 UI만 미리 볼 수 있으며, 경로 세션 생성에는 서버 실행이 필요합니다.

## 인터넷 시연을 위한 배포

Node.js 웹 서버를 실행할 수 있는 호스팅에 이 폴더를 배포합니다. 설치 명령은 `npm install --ignore-scripts`, 시작 명령은 `npm start`입니다. pnpm 환경에서는 포함된 잠금 파일을 이용해 `pnpm install --frozen-lockfile --ignore-scripts`로 설치할 수 있습니다.

- `PUBLIC_BASE_URL`: 실제 발급받은 HTTPS 주소. 하위 경로 없이 지정합니다. 예: `https://your-demo.example`
- `HOST`: 호스팅에서는 `0.0.0.0` 설정. 기본값은 로컬 전용 `127.0.0.1`
- `PORT`: 호스팅이 할당한 포트. 로컬 기본값 3080

공개 주소를 설정해야 실제 휴대폰용 QR이 나타납니다. 서버 실행만으로 공개 배포가 되는 것은 아닙니다. 현재 공개 배포는 별도 수행 대상이며 URL이 발급된 상태가 아닙니다.

## 시연 순서

1. 키오스크에서 한국어 또는 English 선택.
2. 준비된 ‘대전역에 가고 싶어요’ 문장을 선택하거나 직접 입력.
3. 대전역인지 확인하면 추천 경로를 바로 안내합니다. 버스 번호·승차 정류장·이동 정류장 수·하차 정류장을 먼저 확인하세요.
   ‘경로 확인했어요’를 누르면 휴대폰으로 이어받을지 묻습니다. 동의한 경우에만 링크를 생성하며, 거절하면 경로를 다시 보여주지 않고 종료 인사를 표시합니다.
4. QR 스캔 또는 링크 전달로 모바일 웹 열기. PC 검토 시 ‘모바일 화면 열기’ 사용.
5. ‘발표자 화면’은 별도 탭/PC에 열어둡니다. 이 제어 링크는 관객에게 공유하지 않습니다.
6. 휴대폰에서 ‘음성 안내 시작’과 ‘탑승했어요’를 각각 선택.
7. 모바일의 ‘시연 재생’을 누르면 8초 간격으로 자동 이동합니다. 같은 버튼으로 일시 정지할 수 있습니다. 별도 발표자 화면의 ‘다음 정류장’과 자동 진행도 사용할 수 있습니다.
8. 휴대폰에 두 정거장 전 → 다음 정류장 하차 → 도착 표시. 하차 후 ‘하차했어요’ 선택.

휴대폰에서 음성을 켠 상태이면 주요 단계에서 브라우저 음성 합성을 요청합니다. 기기 음성 설정과 브라우저 정책에 따라 소리가 안 날 수 있어 화면과 ‘다시 듣기’를 함께 제공합니다. 진동은 지원 기기에서만 시도합니다. 화면 잠금/백그라운드 알림이나 실제 GPS 기능을 보장하지 않습니다.

## 구조

- `public/index.html`: 키오스크
- `public/mobile.html`: 모바일 안내
- `public/control.html`: 발표자 제어
- `public/app.js`, `public/styles.css`: 화면 로직과 공통 디자인
- `server.cjs`: 세션·QR·이동 상태 서버
- `package.json`: 실행 명령과 QR 라이브러리 의존성

서버는 경로 ID, 언어, 단계, 정류장 인덱스를 메모리에 보관합니다. 세션은 2시간 후 만료되고 서버 재시작 시 삭제됩니다. 모바일 링크와 별도의 제어용 토큰을 사용합니다. 실제 계정·지도 API·LLM·NFC·GPS·영구 DB는 연결하지 않습니다. API에 저장된 정보는 시연 데이터뿐입니다.

모바일 링크를 가진 사람은 데모 자동 재생·일시 정지를 할 수 있습니다. 한 정류장씩 수동 이동하거나 경로를 초기화하는 기능에는 발표자 제어 키가 필요합니다. 모바일의 재생 조작은 실제 이용자 서비스 기능이 아닌 발표용 모의 이동 기능으로 구분해 표시합니다.

## 검증

2026-09-24, Microsoft Edge 자동화와 서버 API 검증을 수행했습니다.

- 한국어·영어 × 경로 A·B의 4개 전체 흐름 통과
- 키오스크와 독립적인 모바일 브라우저 세션 사이의 경로 전달 확인
- 탑승 → 발표자 제어 → 이동 → 다음 정류장 알림 → 도착 → 하차 확인 → 초기화 확인
- 8초 간격 자동 진행 및 일시 정지 확인
- 다른 이용 세션과 상태 분리, 잘못된 제어 키 거부, 탑승 전 이동·도착 전 종료 거부
- 유효하지 않은 링크와 지원하지 않는 목적지 안내 확인
- 공개 주소 미설정 시 QR 비활성화, 테스트 HTTPS 주소 설정 시 QR SVG 생성 확인
- 키오스크 화면 폭 1440 / 1024 / 768 / 390px에서 가로 넘침 없음
- 390px 모바일 화면 캡처 확인, JavaScript 실행 오류 없음

`artifacts` 폴더에 키오스크·모바일 단계별 캡처를 남겼습니다. 자동화 스크립트는 `verify.cjs`입니다. 재실행하려면 서버를 켜고 Playwright 및 Microsoft Edge가 있는 환경에서 실행합니다. Playwright가 별도 경로에 있으면 `PLAYWRIGHT_MODULE` 환경 변수로 지정합니다.

실제 안드로이드 기기의 QR 스캔·음성·진동, 외부 인터넷 접속, 공개 호스팅 배포는 아직 검증하지 않았습니다. 음성 출력은 사용자 버튼으로 활성화한 뒤 주요 단계에 요청하지만 브라우저 지원에 따라 달라집니다.

## 발표 전 준비

공개 주소로 배포한 뒤 키오스크와 발표자 PC, 모바일 데이터에 연결된 안드로이드 휴대폰으로 최종 리허설이 필요합니다. 메모리 세션 구조이므로 서버는 단일 인스턴스로 실행합니다. 서비스가 유휴 상태에서 중지되거나 재시작되면 기존 링크를 새로 만들어야 합니다. 이 프로토타입은 일반 이용자에게 실제 버스 이용을 안내하는 운영 서비스가 아닙니다.

## 이동 안내 개선

- 이전에는 발표자 조작 없이는 모바일 안내가 진행되지 않았습니다. 모바일의 별도 ‘발표용 시연’ 영역에서 재생·일시 정지를 할 수 있도록 보완했습니다.
- ‘안내 다시 듣기’ 버튼을 이동 정보 바로 아래에 배치하고, 남은 정류장 카드와 정류장 표시의 대비를 높였습니다.
- 같은 모바일 탭에서 다른 안내 링크를 열면 새 세션을 불러오며, 이전 세션 응답과 오래된 상태가 화면을 덮어쓰지 않도록 보완했습니다.
- 서버를 재시작하면 기존 시연 링크가 만료됩니다. 키오스크에서 새 경로를 선택해 주세요.
- 추가 검증: 모바일만으로 재생 → 일시 정지 → 재개 → 하차 알림 → 도착 → 종료 통과. 같은 탭의 다른 경로 전환, 오래된 응답 무시, 영어 제어 문구, 320/390/768px 화면, 듣기 버튼 위치를 `verify-mobile.cjs`로 확인했습니다. 기존 4개 전체 시나리오 검증도 통과했습니다.

## 추천 경로 안내 변경

경로 목록에서 고르는 단계를 없앴습니다. 준비된 시연 데이터 중 소요 시간이 가장 짧은 경로를 바로 안내하고, 이를 확인한 다음 별도의 휴대폰 이어받기 질문을 표시합니다. 실제 교통 API 기반 추천은 아닙니다. 이전 검증 기록의 A·B 경로 선택은 변경 전 흐름입니다.

`verify-recommendation.cjs`로 한국어·영어의 추천 경로 선안내, 별도 동의 단계, 거절 시 세션 미생성, 동의 후 동일 경로·언어 인계를 검증했습니다.

## 지도 예시와 버스 번호
추천 경로에 자체 제작한 SVG 지도 예시를 추가했습니다. 파란색 승차점·이동 경로와 주황색 하차점을 표시합니다. 기본 안내 버스는 임의 번호 825번(보조 시연 데이터 826번)이며 실제 노선과 관계없습니다. 지도는 실제 지리나 도로 형상을 재현하지 않은 개략도입니다. 한국어·영어에서 추천 경로 안내와 동일 버스 번호의 모바일 인계를 검증했습니다.

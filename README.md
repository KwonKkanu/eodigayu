# 어디가유 사용법

## 설치 및 실행

1. GitHub에서 ZIP을 다운로드하고 **전체 압축을 해제**합니다.
2. 컴퓨터에 [Node.js LTS](https://nodejs.org/)를 설치합니다. npm도 함께 설치하세요. 이미 설치되어 있으면 생략합니다.
3. 프로젝트 폴더의 **`start.cmd`를 더블클릭**합니다. 첫 실행 시 필요한 라이브러리를 자동 설치하므로 인터넷 연결이 필요합니다.
4. 실행 창에 `Bus demo:`가 나타나면 브라우저에서 **http://localhost:3080**을 엽니다.

사용하는 동안 실행 창을 켜두세요. 종료하려면 실행 창에서 **Ctrl+C**를 누릅니다.

터미널에서 직접 실행하려면 프로젝트 폴더에서 다음 명령을 입력합니다.

```sh
npm install --ignore-scripts
npm start
```

## 데모 이용 순서

1. **한국어** 또는 **English**를 선택합니다.
2. **대전역에 가고 싶어요** 예시를 누르거나 목적지를 입력합니다.
3. 목적지를 확인하고 추천 경로의 지도·버스 번호·승하차 정류장을 확인합니다.
4. **경로 확인했어요**를 누릅니다.
5. **네, 휴대폰으로 이어받을게요**를 선택합니다. **아니요, 안내를 종료할게요**를 선택하면 종료 인사가 표시됩니다.
6. **모바일 화면 열기**로 안내 화면을 엽니다. PC에서도 별도 탭으로 확인할 수 있습니다.
7. 모바일 화면에서 필요하면 **음성 안내 시작**을 누르고, **탑승했어요**를 선택합니다.
8. **시연 재생**을 누르면 8초마다 다음 정류장으로 이동합니다. **일시 정지**로 멈출 수 있습니다.
9. 하차 알림과 도착 안내를 확인한 뒤 **하차했어요**를 누르면 종료됩니다.

음성을 들으려면 화면을 켜둔 상태에서 기기의 미디어 음량을 확인하세요. 버스 번호·지도·이동 상황은 시연용이며 실제 길찾기에 사용하지 마세요.

## 발표자 화면 사용

휴대폰 연결 화면에서 **발표자 화면 열기**를 선택합니다.

- 모바일에서 탑승을 확인한 후 **다음 정류장으로**를 누르면 한 정류장씩 이동합니다.
- **자동 진행 시작**으로 자동 이동하고, 다시 눌러 멈춥니다.
- **같은 경로로 처음부터**를 누르면 탑승 대기 상태로 돌아갑니다.

## 실제 휴대폰으로 열기

`localhost` 주소는 실행 중인 PC에서만 사용할 수 있습니다. 다른 네트워크의 휴대폰으로 접속하려면 공개 HTTPS 서버에 배포해야 합니다.

Node.js를 지원하는 호스팅에서 다음과 같이 설정합니다.

| 항목 | 설정 |
| --- | --- |
| 설치 명령 | `npm install --ignore-scripts` |
| 실행 명령 | `npm start` |
| `PUBLIC_BASE_URL` | 발급받은 HTTPS 주소. 하위 경로 없이 입력 |
| `HOST` | `0.0.0.0` |
| `PORT` | 호스팅에서 지정한 포트 |

배포한 주소로 키오스크를 열면 경로를 이어받는 QR이 표시됩니다. 휴대폰 카메라로 스캔하거나 링크를 전달해 접속하세요.

## 실행이 안 될 때

- **Node.js 또는 npm을 찾지 못함:** Node.js 설치 시 npm과 PATH 추가를 포함하고, 기존 실행 창을 닫은 뒤 다시 실행하세요.
- **라이브러리 설치 실패:** 인터넷 연결을 확인하고 `start.cmd`를 다시 실행하세요.
- **`EADDRINUSE` 오류:** 서버가 이미 실행 중일 수 있습니다. http://localhost:3080으로 접속하거나 기존 서버를 종료한 뒤 다시 실행하세요.
- **안내 링크 만료:** 서버 재시작 또는 링크 생성 후 2시간 경과 시 키오스크에서 새 안내 링크를 받으세요.
- **수정한 화면이 보이지 않음:** 브라우저에서 **Ctrl+F5**로 새로고침하세요.
